Agent42 browser bridge

Lets your Agent42 conversations use this Chrome, with your sign-ins. In Agent42, add an MCP server with authentication Local bridge, then paste its bridge key here.

No browser action runs on these sites or their subdomains, not even evaluate. The Agent42 site itself is blocked by default.

Know what this allows. The agent can see and act on every open tab. Its evaluate tool runs JavaScript in a page without asking, and it can be reached from agent runs, API keys, reminders and inbound email, not only from chats you are watching. Text on a web page can steer the agent. Keep sensitive sites on the blocked list, and narrow this server's tools in Agent42 for agents that others can reach.
