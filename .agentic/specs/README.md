# Specs

Plans for work spanning multiple sessions or MRs. Naming: `plan-<topic>.md`.
Move to `completed/` in the MR that finishes the work. A spec that must stay
current (living document) stays here with a `refresh:` note in its header.

Keep specs about intent and sequencing — implementation detail lives in the code
and its MR. Delete specs that were abandoned rather than completed (note why in
the deleting commit message).
